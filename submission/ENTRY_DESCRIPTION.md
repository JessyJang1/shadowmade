# 影生万物 SHADOWMADE

## 选题简介

平安夜，雪镇的钟停了。你是一道还没有形体的影子，循着一张纸条走进旧工坊，发现两件普通物品的影子合在一起，竟能拼出一颗星。

《影生万物》是一款手绘绘本风格的 3D 解谜游戏。亲手摆动物件、挪动灯光，让星星回到钟楼，让影子变成能走过去的桥，再从幕布另一侧找回灯塔的光。故事结束时，你可以把亲手唤醒的雪镇做成一张圣诞贺卡。

Aholo Lux3D 创作了钟楼、工坊和广场木马等资产。我们还把生成模型的一部分改成风轮铜翼、桥板和遮光门。玩家实际操作这些物件，它们投出的影子决定三道谜题能否解开。
